# Junior Security Analyst Intro

## Overview
- **Platform:** TryHackMe
- **Learning Path:** SOC Level 1
- **Status:** Completed

## Objective
Understand the responsibilities of a Junior Security Analyst and how the role contributes to security monitoring and incident investigation.

## Key Concepts
- Security Operations Centre (SOC)
- Security monitoring and alert investigation
- Identifying suspicious activity
- Incident handling and escalation

## What I Learned
1. A SOC helps monitor and investigate potential security incidents.
2. Security analysts review alerts and assess whether activity is suspicious.
3. Analysts follow incident-handling procedures and escalate cases when necessary.
