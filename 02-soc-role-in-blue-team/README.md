# SOC Role in Blue Team

## Overview
- **Platform:** TryHackMe
- **Learning Path:** SOC Level 1
- **Status:** Completed

## Objective
Understand the role of a Security Operations Centre (SOC) in defending an organisation and learn about the responsibilities of a Level 1 (L1) SOC analyst.

## Key Concepts
- Blue Team operations
- SOC structure and responsibilities
- L1 analyst duties
- Security monitoring and alert triage
- Incident escalation and reporting

## What I Learned
1. A SOC helps monitor security events and investigate potential threats.
2. L1 analysts review alerts, perform initial triage, and identify suspicious activity.
3. Analysts document their findings and escalate incidents according to established procedures.

## Skills Developed
- Understanding SOC workflows
- Security alert triage concepts
- Incident reporting
- Defensive security awareness
